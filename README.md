# WebSocket Chat

[![Deploy frontend](https://github.com/MrRodionGrigorev/ahj-websocket-chat/actions/workflows/deploy.yml/badge.svg)](https://github.com/MrRodionGrigorev/ahj-websocket-chat/actions/workflows/deploy.yml)

[GitHub Pages](https://mrrodiongrigorev.github.io/ahj-websocket-chat/)

[Backend on Render](https://ahj-websocket-chat.onrender.com/)

```bash
npm install
npm start
```

Frontend: `http://127.0.0.1:8081`. Backend: `http://127.0.0.1:3000`.

Для Render: Root Directory — `backend`, Build Command — `npm install`, Start Command — `npm start`.
После создания Render-сервиса добавьте его HTTPS-адрес в GitHub Actions variable `API_URL`.
